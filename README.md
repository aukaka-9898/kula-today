# Kula Today

A daily soaring briefing for Kula, Maui: measured conditions on the slope,
the live Kekoa webcam, sunlight up the mountain, and the week's outlook.

GitHub Actions rebuilds `docs/index.html` every 30 minutes in daylight
(`build.py` + `template.html`) and GitHub Pages serves it. The forecast code
comes from a separate private repository at build time.

Hobby project. Information only, provided as is, with no guarantee of
accuracy or availability. This is not an official forecast. Every pilot is
responsible for their own decision to fly.

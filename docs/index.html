Why?

I'm a 50+ year Hawaiʻi hang glider pilot, on Oʻahu these days, but spent a decade or so on Maui running Maui School of Hang Gliding. A self-unemployed hang gliding instructor.

Back in the day we struggled to understand how the Kula “bubble” responds to the more general weather patterns and came to the conclusion that the situation was just too complex; with the wind shadow, giant slope and diurnal flows really messing with things. Not to mention the Pukalani shear. Unless there was an obvious large scale pattern moving through the islands it was more about “feel” than science.

But now there is a large amount of live data available. Several forecast models (and their output) as well as multiple surface stations providing realtime data. The idea is, with these resources it may be possible to, if not provide a true forecast, come up with some “rules”. Compare what is happening now with what the forecasts called for. See if there are patterns in the variances. See if those large scale patterns produce their own patterns in Kula.

That’s the plan anyway, so far it seems it might be working. Maybe not well enough to say, “Screw work, I’m going flying tomorrow!” Not yet. But more data might get us closer. Actual in flight data can be hugely important toward this.

So why start with such a challenging location? Two reasons, mostly.

  • I loved flying in Kula. While it may not be as spectacular as other places it is just so enjoyable.
  • If an effective set of rules can be developed here, most other sites will be a piece of cake.
